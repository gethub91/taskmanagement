## Project Overview

Task Management System is a web application developed using HTML, CSS, and JavaScript.

It helps users manage their daily tasks easily.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Visual Studio Code
- Git and GitHub

## Features

1. Add new tasks.
2. Select task priority.
3. Mark tasks as completed.
4. Undo completed tasks.
5. Delete tasks.
6. Filter pending and completed tasks.
7. Display task statistics.
8. Save tasks using LocalStorage.
9. Responsive design.

## Project Files

- index.html
- style.css
- script.js
- README.md

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in Google Chrome.
4. Start adding and managing tasks.
